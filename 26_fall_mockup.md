# Fall Project Guidelines

## Project Overview

During the Fall Quarter, Geniuses will design and develop a working website connected to their Radical Social Entrepreneurship business idea.

The goal of this project is for Geniuses to apply the technical skills they are learning throughout the quarter while continuing to develop a product that addresses a real need or problem.

Geniuses will use HTML, CSS, JavaScript, Flask, databases, and Artificial Intelligence throughout the development process.

Artificial Intelligence will be introduced as a tool that can support research, planning, development, debugging, testing, and product improvement.

The expectation is not for AI to complete the project. Geniuses should understand the decisions being made, understand the code being added to their project, and be able to explain how AI supported their development process.

## Final Project Goal

Each Genius or team will create a functional web application connected to a Radical Social Entrepreneurship business.

The final product should clearly communicate the problem being addressed, who the product is designed for, how the product works, and how the business could create sustainable impact.

## Project Requirements

### 1. Problem and Purpose

The project should address a clear problem or need.

Geniuses should be able to explain:

Who experiences the problem

Why the problem matters

What currently exists to address the problem

How their product provides value

### 2. Target User

Every project should have a clearly identified user or customer.

Geniuses should understand who they are building for and make product decisions based on the needs of that user.

### 3. Website Development

The final website should include:

A clear home or landing page

Organized navigation

Consistent styling

Multiple sections or pages when appropriate

A layout that works across different screen sizes

Content that clearly explains the product or business

### 4. JavaScript

Each project should include at least three meaningful JavaScript features.

Examples may include:

Forms

Search functionality

Filtering

Interactive buttons

Calculators

Dashboards

Dynamic content

Quizzes

User input

Data visualization

The JavaScript should improve how the user interacts with the product and should not be added only to meet the requirement.

### 5. Flask

The final project should use Flask to connect the front end and back end of the application.

Geniuses should demonstrate an understanding of:

Routes

Templates

Static files

Passing information between pages

Connecting the website to application logic

### 6. Database

Each project should store, retrieve, or manage information through a database or another approved data source.

The database should support the purpose of the product.

## Prompting Guidelines

A strong prompt should give AI enough information to understand what is being built and what type of help is needed.

Geniuses should focus on five areas when writing prompts.

### Context

Explain what you are building.

### User

Explain who the product is designed for.

### Task

Clearly explain what you want the AI to help with.

### Requirements

Explain what the response should include, avoid, or consider.

### Follow Up

Review the response and continue the conversation when additional clarification or improvement is needed.

### Example Prompt

I am building a website that helps high school students find local mental health resources. My target users are students between the ages of 14 and 18. Review my current feature ideas and identify anything that may be confusing, unnecessary, or missing. Give me three improvements that would be realistic for a student project using JavaScript and Flask.

## Using AI During Development

Geniuses may use AI throughout the project to support different parts of the development process.

AI may be used for:

Product research

Brainstorming

Planning features

Creating user personas

Improving user experience

Explaining programming concepts

Reviewing code

Debugging errors

Testing ideas

Improving written content

Reviewing the final product

AI should help Geniuses make stronger decisions.

It should not replace their ability to think through a problem or understand what they are building.

## Expectations for AI Generated Code

Geniuses may use AI to assist with programming, but they are responsible for understanding the code inside their project.

Before adding AI generated code, Geniuses should be able to explain:

What the code does

Why the code is needed

How the code connects to the rest of the project

What information the code receives

What result the code produces

Geniuses should also test any code suggested by AI before considering the feature complete.

Code that cannot be explained should not be included in the final project.

## Responsible AI Use

AI systems can produce incorrect, incomplete, or biased information.

Geniuses are responsible for reviewing information before using it.

Do not enter private or sensitive information into AI tools.

Important facts should be verified.

AI recommendations should be treated as suggestions.

The Genius or team is responsible for the final decision.

### Working Product

A functional Flask web application that can be demonstrated.

### GitHub Repository

A complete and organized repository containing the project code.

### AI Development Log

At least five examples showing how AI was used to support the development process.

### Project Summary

A short overview explaining the problem, target user, solution, main features, and technology used.

### RSE Business Plan

A clear explanation of the target customer, value proposition, marketing strategy, financial strategy, and intended social impact.

### Final Presentation

Each team will present their product and demonstrate how it works.

The presentation should explain the problem, the solution, the target user, the technology used, the business model, the role AI played in development, and the potential impact of the product.

## Final Expectation

AI is one of the tools available during that process.

Geniuses are still responsible for the idea, the decisions, the code, and the final product.
